- 降水：500/700/850hPa相对湿度/垂直速度、700/850hPa比湿/水汽通量散度/散度；
- 强对流：K指数、SI（沙氏指数）、对流有效位能、CIN、850-500 hPa温度差、风切变0-6km……
用于 2–6h 短时预报，判断环境是否支持对流发展、维持、加强，减少误报。
- 数据时效
0–24h
- 关注重点
①热力条件（不稳定层结）：对流有效位能≥1000J/kg（对流能量充足）、≥2000J/kg（强对流高潜势）；
②水汽条件：850hPa比湿＞8g/kg；700hPa水汽通量散度≤-10×10⁻⁷g/(cm²・hPa・s)（强降水潜势）；
③动力条件：500hPa垂直速度上升运动，天气系统影响；水平风垂直切变0-6km（组织化与大风潜势），12、15、20；
对流指数：K指数32、35、38℃，沙氏指数小于0
