# 强对流四类灾害判定规则

## 1、强对流说明

*   强冰雹
    
*   雷暴大风
    
*   短时强降水
    
*   超级单体龙卷
    

## 2、要素单位说明

*   CAPE：对流有效位能，单位 J/kg
    

*   0-6km 风切变：单位 m/s
    

*   0-1km 风切变：单位 m/s
    

*   RH：相对湿度
    

*   BLI：抬升指数
    

*   T850−500​：850hPa 与 500hPa 温度差
    

*   湿球 0℃层高度：单位 km
    

*   LCL：抬升凝结高度，单位 km
    

## 3、判定规则

*   全部条件同时满足：判定 → 有利于出现该类强对流天气
    

*   仅单项条件不满足，其余全部达标：判定 → 有可能出现该类强对流天气
    

*   两项及以上条件不满足：判定 → 不利于出现该类强对流天气
    

## 4、判定条件

### 一、强冰雹（直径≥2cm）判定条件

1、能量条件： -10℃～-30℃ 高度层存在有效 CAPE 且CAPE≥1000 J/kg；

2、动力条件： 0-6km垂直风切变\> 10 m/s；

3、融化层条件： 低海拔地区2.0km≤湿球0°层高度≤4.5km。

### 二、雷暴大风（不含脉冲风暴）判定条件

1、能量条件： CAPE>500J/kg 且BLI≤-29；

2、动力条件： 0-6km垂直风切变\>10m/s(中等及以上)；

3、干层条件： 700hPa ~ 400hPa区域且RH < 80%；

4、层结温差： T850-500 >25℃。

### 三、短时强降水判定条件

1、能量条件： CAPE>0J/kg；

2、低层湿度：地面~850hPa低层且RH>80%（925hPa~850hPa为深厚湿层，地面持续湿层为加强条件）；

3、动力条件：0-6km垂直风切变\>6m/s。

### 四、超级单体龙卷判定条件

1、能量条件：CAPE > 1500J/kg；

2、深层风切变：0-6km垂直风切变\>20m/s；

3、低层风切变：0-1km垂直风切变\>10m/s；

4、抬升条件：LCL < 1.2km。
