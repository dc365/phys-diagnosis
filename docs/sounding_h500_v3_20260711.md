# 探空 H500 自适应分析 v3

## 目标与约束

本次优化只使用 `regional_radiosonde*.csv` 中的探空站资料，不引入 EC、CMA、GRAPES 或其他数值模式格点背景场。

业务目标是改善 2026 年 6 月 24—25 日测试时次中以下结构：

- 华南—海南附近的 588 dagpm 等高线；
- 蒙古—俄罗斯中部约 105—107°E 的高空槽；
- 俄罗斯远东—东北—朝鲜半岛附近约 127—129°E 的高空槽；
- 避免重新生成把相邻槽区连接起来的东北斜向伪槽线；
- 切变线继续使用独立风场算法和 Map 独立开关。

## 纯探空站自适应 Z500 分析

新增模块：

```text
weather_diag/diagnosis/sounding_z500_adaptive.py
```

核心链路：

```text
探空廓线
  -> 500hPa 垂直插值和质控
  -> 既有 900/650/450km Barnes 基准场
  -> 纬向稳健趋势 + 1450km 探空站距平场
  -> 中高纬 900/600/350km Barnes 融合
  -> 高纬 300km 站点增量细化
  -> 低纬经向较弱、纬向较强的各向异性平滑
  -> Z500 自适应天气尺度分析场
```

所有背景、趋势和增量均由同一时次探空站资料生成。

### 中高纬处理

32°N 以北逐渐提高纬向 Barnes 场的权重，46°N 附近达到最大权重；同时在观测较密区域加入 300km 小半径站点增量，以恢复蒙古、俄罗斯和东北区域的高度谷曲率。

### 华南和海南处理

18—30°N 逐渐施加低纬正则化，纬向平滑尺度大于经向平滑尺度，减少稀疏海洋探空资料造成的紧凑 588 dagpm 小闭合圈，使副热带高度场更接近连续的天气尺度边界。

### 运行时范围

自适应分析只在以下完整条件同时成立时启用：

- 字段为 `geopotential_height_m`；
- 半径为 `900/650/450 km`；
- 增益为 `1.0/0.85/0.55`；
- 平滑参数为 `1.0`；
- 支持距离为 `850 km`；
- 已提供探空站生成的第一猜测场。

其他气象要素、其他层次以及数值模式/NAFP 客观分析不受影响。

为兼容现有接口，公开的 `analysis_version` 暂保留 `sounding_z500_synoptic_v2`，并新增：

```json
{
  "adaptive_analysis_version": "sounding_z500_synoptic_v3",
  "adaptive_station_only": true,
  "background_method": "station_only_adaptive_multiscale"
}
```

## 槽线识别优化

### 等高线种子

等高线槽尖算法现在同时保留：

- 多个相邻等高线层次共同支持的种子；
- 通过 Otsu 自动阈值的强单层种子。

以前只要存在多层种子，所有单层强种子都会被丢弃，容易漏掉蒙古和俄罗斯远东较弱但真实的槽。

### 高纬延伸

34°N 以北的等高线种子可以沿连续高度低谷向北延伸更远，不再被固定的 2.5—4° 纬度边距截短。

### 独立区域低谷追踪

新增两个狭窄、自动追踪的高度谷走廊：

1. `south_china_hainan`：105—114°E、13—21°N；
2. `mongolia_russia_central`：99—112°E、38—55°N。

它们只提供 `meridional_valley_track`，不会补回容易形成东北斜向桥接线的广域 PCA 候选轴。

## 仍需业务核验的边界

中央台业务图可能还使用更多观测资料、时间连续性约束及人工订正。纯探空站方案的目标是获得稳定、可解释、可自动运行的天气尺度结构，而不是保证与单张中央台图逐像素一致。

当前需重点人工核验：

- 海南 588 dagpm 线是否仍存在不合理的局地闭合；
- 蒙古—俄罗斯中部槽的南端位置；
- 远东槽与朝鲜半岛低涡槽是否应拆成两个独立分支；
- 四个测试时次之间槽线是否具有合理时间连续性。
