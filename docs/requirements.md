# MVP 需求规格说明书 v0.1

## 目标

基于 EC 模式 NetCDF 格点资料，自动计算气象物理量，识别主要天气系统，并通过 Web GIS 展示，生成可解释的天气形势分析。

## 第一版范围

- 数据：ECMWF/EC NetCDF
- 诊断量：风速风向、散度、涡度、涡度平流、温度平流、水汽通量、水汽辐合、K 指数、0–6km 风切变近似、风险评分
- 天气系统：高压、低压、副高 5880 区、槽脊候选、辐合区、辐散区、低空急流、水汽输送带、锋面候选、强降水/强对流潜势区
- 展示：MapLibre Web GIS、诊断格点 GIS 图层、天气系统 GeoJSON、模式/要素/时间轴交互、点击证据、自动分析

## 暂不实现

- 完全准确锋面绘制
- 深度学习识别
- 多模式融合
- 雷达/卫星/自动站实时融合
- 三维可视化
- 高并发生产架构
