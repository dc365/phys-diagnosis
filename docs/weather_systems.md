# 天气系统定义与算法说明

本文档说明项目中地图与诊断接口输出的主要天气系统定义、输入数据、识别算法、输出几何和业务解释口径。当前第一版以 EC/NAFP NetCDF 格点数据为主，并开始支持 sounding 站点资料生成客观分析场后识别天气系统；所有算法均属于客观诊断候选，不直接从中央台天气图图片中提取线段或区域。

## 1. 总体原则

天气系统自动识别遵循四个原则：

1. **先统一数据再诊断**：位势高度、气压、温度、风、湿度、降水等变量在数据读取阶段完成单位归一、维度裁剪、时效处理和缺测处理。
2. **天气尺度优先**：槽线、副高、低空急流、水汽输送带等对象先做适度平滑、面积过滤或长度过滤，避免把单格点噪声识别为天气系统。
3. **多证据约束**：能使用动力、热力和水汽支撑的系统，不只依赖单个百分位阈值。例如锋面候选同时使用温度梯度、锋生、形变、辐合和温度平流。
4. **业务展示与调试分离**：业务图层尽量输出 Point、LineString 或平滑 Polygon；原始 mask、bbox、连通区等只作为 debug 或 evidence 信息，不直接作为主图层展示。

## Sounding 客观分析天气系统

Sounding 资料按观测时次和气压层组织，不使用模式 `run_time` / `forecast_hour`。系统先把站点 500hPa 位势高度、温度和风做 1 度客观分析，再输出 `height_high`、`height_low`、`warm_center`、`cold_center`、`trough_candidate` 和 `ridge_candidate`。每个对象必须带 `feature_type`、`confidence`、`geometry` 和 `evidence`；站点稀疏度和最近站距离会进入质量信息，避免把稀疏站点场展示成确定性模式格点。

## 2. 地面高压中心 / 低压中心

**业务定义**：海平面气压场中的天气尺度高压或低压中心。高压中心通常对应闭合等压线内的气压高值，低压中心对应闭合等压线内的气压低值。

**输入要素**：

- `mslp` / `seap`：海平面气压，单位统一为 hPa。

**算法步骤**：

1. 对海平面气压场做轻量平滑，降低单格点极值噪声。
2. 在平滑场中查找局地最大值和局地最小值。
3. 用 `min_distance_km` 控制中心间距，用 `edge_margin_km` 剔除边界伪极值。
4. 从中心值向外按 `contour_interval_hpa` 逐圈检查闭合等压线。
5. 同时满足 `min_prominence_hpa`、`min_closed_contours`、`min_closed_area_km2` 后输出中心。

**输出几何**：Point。

**主要属性**：中心经纬度、中心气压、闭合等压线圈数、最外闭合等压线值、闭合面积、置信度。

## 3. 500hPa 副热带高压 588 区

**业务定义**：500hPa 位势高度达到或超过 588dagpm / 5880gpm 的连续区域。项目中该对象用于表示副高主体，并计算西伸脊点、南北界、东西界和面积强度。

**输入要素**：

- `gh500`：500hPa 位势高度。若数据为 dagpm，阈值用 588；若数据为 gpm，阈值用 5880。

**算法步骤**：

1. 根据高度场量级自动判断使用 588 或 5880 阈值。
2. 生成 `gh500 >= threshold` 的副高候选 mask。
3. 提取最大或主要连通区，过滤面积过小斑块。
4. 统计最大高度、平均高度、面积格点数、东西边界、南北界。
5. 在最西侧达到阈值的格点中选高度最高点作为西伸脊点。
6. 根据经向/纬向跨度判断主体形态：纬向型、经向型或紧凑型。
7. 对业务展示的 Polygon 边界做局地公里坐标平滑：先以 `boundary_smooth_km` 对格点台阶边界做圆角化，再以 `boundary_simplify_km` 做拓扑保持简化。该步骤只改变地图显示边界，不改变面积格点数、平均高度、西伸脊点等诊断统计。

**输出几何**：平滑 Polygon / MultiPolygon。

**主要属性**：`center`、`ridge_point`、`north_boundary_lat`、`south_boundary_lat`、`west_boundary_lon`、`east_boundary_lon`、`area_grid_points`、`max_height`、`mean_height`、`axis_orientation`、`boundary_smoothed`。

**注意事项**：588 区边界来自格点场，不会和人工天气图完全一致。业务上应结合等高线、槽线、水汽输送和实况订正副高边缘降水触发位置。

## 4. 500hPa 槽线候选 / 脊线候选

**业务定义**：500hPa 高度场中的天气尺度槽轴或脊轴。槽线表示相对低值伸展轴，脊线表示相对高值伸展轴。

**输入要素**：

- `gh500`：500hPa 位势高度。
- `uv500`：500hPa 风场，可选，用于相对涡度支撑。

**算法步骤**：

1. 计算纬向平均背景场，得到 `gh500 - zonal_mean(gh500)` 距平。
2. 对距平场做轻度平滑，计算梯度、拉普拉斯、等高线曲率。
3. 槽线使用低端距平分位，脊线使用高端距平分位，形成候选带。
4. 候选带还需满足曲率或局地轴线评分支撑，减少大片异常区边界误报。
5. 若有 `uv500`，槽线要求正涡度支撑，脊线要求负涡度支撑。
6. 对候选点构造主轴，按评分抽取轴线点，然后进行 B 样条平滑。
7. 输出 LineString；不在业务主图层输出候选 mask 或 bbox 面。

**输出几何**：LineString。

**主要属性**：`threshold_value`、`curvature_mean`、`vorticity_support_mean`、`axis_length_km`、`sinuosity`、`method`、`rank`。

**注意事项**：中央台图例中的棕色线段可能是槽线或切变线，因此本算法只代表 Z500 槽/脊候选；风场切变线需单独算法识别。

## 5. 低压辐合区 / 高压辐散区

**业务定义**：500hPa 高度距平中心与 850hPa 低层散度配合形成的综合候选区。低压辐合区表示高度负距平和低层辐合重叠，高压辐散区表示高度正距平和低层辐散重叠。

**输入要素**：

- `gh500`：500hPa 位势高度。
- `div850`：850hPa 散度。

**算法步骤**：

1. 计算 `gh500` 纬向距平。
2. 低压辐合：高度距平小于低端分位，`div850` 小于低端分位。
3. 高压辐散：高度距平大于高端分位，`div850` 大于高端分位。
4. 对叠加 mask 提取连通区，按面积和显著性排序。
5. 输出候选区及均值证据。

**输出几何**：Polygon。

**主要属性**：平均高度距平、平均散度、连通面积、排序、置信度。

## 6. 850hPa 低层辐合区

**业务定义**：低层风场水平辐合明显的区域，是强降水和强对流触发的重要动力条件。

**输入要素**：

- `div850`：850hPa 散度。
- `uv850`：850hPa 风场，可选，用于反算散度和符号一致性校验。

**算法步骤**：

1. 对散度场做轻度平滑。
2. 同时使用绝对阈值和区域分位阈值：散度必须足够负，不能只是在弱场中“相对偏低”。
3. 可选使用风场反算散度，要求符号与产品散度一致。
4. 使用形态学 closing/opening 消除孤立噪声。
5. 过滤小面积、弱平均强度和弱最大强度对象。
6. 按面积和强度排序输出主辐合区。

**输出几何**：Polygon。

**主要属性**：`area_km2`、`mean_strength`、`max_strength`、`threshold_value`、`percentile_threshold`、`absolute_threshold`。

## 7. 200/300hPa 高空辐散区

**业务定义**：高空正散度显著区域，常与低层辐合配合，代表上空抽吸和补偿上升环境。

**输入要素**：

- `div200` / `div300`：200hPa 或 300hPa 散度。

**算法步骤**：

1. 优先检查 200hPa 和 300hPa 散度场。
2. 对散度场做轻度平滑。
3. 同时要求正散度绝对阈值和高端分位阈值。
4. 进行面积、平均强度和最大强度过滤。
5. 多层候选统一排序，保留最主要对象。

**输出几何**：Polygon。

**主要属性**：层次、面积、平均/最大辐散强度、阈值来源、置信度。

## 8. 水汽辐合区

**业务定义**：水汽通量散度为负的区域，表示水汽在低层聚集，是持续性强降水的重要条件之一。

**输入要素**：

- `q850`：850hPa 比湿。
- `uv850`：850hPa 风场。

**算法步骤**：

1. 计算水汽通量 `Fq = q * V`。
2. 计算水汽通量散度 `∇·Fq`，取负值表示水汽辐合。
3. 平滑后使用低端分位阈值提取候选区。
4. 与水汽通量强度配合过滤，避免干区弱辐合误报。
5. 输出主水汽辐合区。

**输出几何**：Polygon。

**主要属性**：水汽通量散度均值、面积、排序、证据链。

## 9. 低空急流

**业务定义**：850hPa 或 925hPa 附近风速显著偏大的低层风带，常用于指示水汽输送、动量下传和强对流组织化环境。

**输入要素**：

- `uv850`：850hPa 风场。
- `q850`：850hPa 比湿，可选，用于水汽通量配合。

**算法步骤**：

1. 计算风速 `sqrt(u²+v²)`。
2. 风速需达到 `wind_speed_min_ms`，且水汽通量达到指定分位。
3. 对候选区计算风向一致性，剔除旋转噪声或风向杂乱区域。
4. 有风场时沿风向做流线式轴线追踪；追踪失败时回退为连通区主轴。
5. 输出线状轴线及必要的源候选区信息。

**输出几何**：LineString。

**主要属性**：轴线长度、平均风速、最大风速、风向一致性、`axis_method`。

## 10. 水汽输送带

**业务定义**：低层水汽通量高值且方向连续的输送带，用于识别降水水汽来源和输送路径。

**输入要素**：

- `uv850`：850hPa 风场。
- `q850`：850hPa 比湿。

**算法步骤**：

1. 计算水汽通量强度 `|qV|`。
2. 使用高端分位提取水汽通量高值带。
3. 计算风向一致性，过滤方向杂乱的局地高值区。
4. 沿 `qV` 方向进行流线式轴线追踪，生成更符合业务认识的输送轴。
5. 输出 LineString，并保留源候选区 bbox 和统计信息。

**输出几何**：LineString。

**主要属性**：平均水汽通量、轴线长度、方向一致性、`axis_method`。

## 11. 锋面候选

**业务定义**：低层温度梯度大、风场形变和辐合配合明显的锋区候选。当前输出为客观候选，尚不强制区分冷锋、暖锋、准静止锋。

**输入要素**：

- `tt850`：850hPa 温度。
- `uv850`：850hPa 风场。
- `div850`：850hPa 散度。
- `ttadv850`：850hPa 温度平流，可选。
- `rh850`：850hPa 相对湿度，可选。

**算法步骤**：

1. 计算 850hPa 温度水平梯度。
2. 由风场计算形变和锋生函数。
3. 使用低层辐合、温度平流变化和湿度作为辅助支撑。
4. 综合评分达到阈值，且至少满足一定数量动力支撑项。
5. 对锋区候选面抽取骨架/主轴，业务图层默认输出 LineString。
6. 面对象只作为调试图层或证据字段保留。

**输出几何**：LineString。

**主要属性**：平均温度梯度、锋生/形变支撑、支撑项数量、源区域 bbox、排序。

## 12. 风险区与天气系统的关系

风险区不是传统天气系统，但会引用天气系统作为成因证据。当前主要风险包括：

- 持续性强降水。
- 短时强降水。
- 雷暴大风 / 下击暴流。
- 冰雹。
- 旋转风暴 / 超级单体潜势。
- 强对流综合风险。

每类风险先在格点上计算 0-1 评分，再提取达到阈值的风险区。风险区会记录主导因子、缺失关键因子、评分封顶情况，并关联附近或重叠的槽线、锋面、低空急流、水汽输送、低层辐合、高空辐散等天气系统。

## 13. 前端渲染建议

- Point：高压中心、低压中心。
- LineString：槽线候选、脊线候选、低空急流、水汽输送带、锋面候选。
- Polygon：副高 588 区、低层辐合、高空辐散、水汽辐合、低压辐合区、高压辐散区、风险区。
- 对 Polygon，优先使用接口返回的 `geometry` 绘制，不要根据 `bbox` 生成展示面。
- 对副高区，`boundary_smoothed=true` 表示已做显示边界平滑；`source_bbox` 仅供定位和调试，不应作为地图面对象绘制。

## 14. 调参优先级

1. 副高边界：优先调 `subtropical_high.boundary_smooth_km` 和 `subtropical_high.boundary_simplify_km`。
2. 槽/脊线：优先调 `trough_ridge.smooth_radius_km`、`seed_percentile`、`spline_smooth_factor`。
3. 辐合/辐散：优先调绝对阈值、分位阈值和 `min_area_km2`。
4. 风险区：优先调风险评分阈值、关键因子完整度和各因子权重。
5. 锋面：优先调温度梯度分位、综合评分分位和最少动力支撑项数量。
