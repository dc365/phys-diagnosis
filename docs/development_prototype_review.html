开发原型定位

以数值预报和实况探空先定势的短临诊断流程

本原型按预报员实际分析顺序组织：数值预报物理量和实况探空/TlogP 先判断环境定势，雷达/卫星再判断回波位置和强度， 风廓线与实况资料用于细化垂直结构、系统进度和短时修正。紧急临近场景下雷达仍是最直接预警信息， 但日常短临分析首要背景是订正后的数值预报物理量和探空实况。

数值预报：EC/GFS 实况探空：福州/南平 雷达/卫星：定点定强 风廓线：实时补充 输出：定性趋势 + 证据链

2. 数值预报物理量模块

本模块只处理 EC、GFS 等数值预报模式资料，输出福州区域未来 0-24h 的环境物理量和模式 TlogP，业务重点关注未来 2-6h。

模块定位

数值预报物理量是短临分析的首要背景资料。TlogP 和物理量每天上午会商前分析； 实际半夜四五点资料到齐后即可提前分析。该模块按模式、起报时次、预报时效输出福州区域的热力、水汽、动力、对流指数和模式 TlogP， 用于判断环境是否支持对流发展、维持或加强。

资料类型：数值预报 模式：EC/GFS 等 时点：上午会商前 重点：2-6h 环境趋势

数据边界

  • EC、GFS 等均属于预报资料，不与探空实况站混在同一数据对象中。
  • 输出按模式、起报时次、预报时效组织，空间范围只做福州区域。
  • 数值预报也提供模式 TlogP 图，与实况探空 TlogP 分开展示。
  • 多模式结论保留差异，再形成融合诊断，不只给平均值。

热力条件 CAPE ≥1000J/kg 能量充足；≥2000J/kg 强对流高潜势 环境具备对流发展、维持或加强的能量基础。 只说明“有能量”，仍需触发和抬升释放。
热力条件 CIN <50J/kg 抑制较弱；50-150J/kg 有抑制；≥150J/kg 抑制强 CIN 小，热力触发更容易；CIN 大，需系统抬升、边界层辐合或地形触发。 高 CAPE + 强 CIN 容易造成“有能量但不爆发”。
热力条件 850-500hPa 温度差 / 中层直减率 850-500hPa 温差 ≥25℃ 为不稳定参考；700-500hPa 直减率 ≥6.5℃/km 偏有利，≥7.5℃/km 较陡 温度随高度下降快，利于强上升和雷暴发展。 南方暖湿环境中需结合湿层深度和触发条件。
水汽条件 850hPa 比湿 >8g/kg 低层水汽较好；≥12g/kg 暖季水汽更充沛 低层水汽输送充足，支持短时强降水和对流维持。 要与风场判断水汽输送方向和入流结构。
水汽条件 500/700/850hPa 相对湿度 850hPa ≥80%、700hPa ≥70%、500hPa ≥60% 表示湿层较深 深厚湿层越完整，降水效率越高，短时强降水潜势越明确。 中层偏干时强降水效率下降，但雷暴大风潜势可能上升。
水汽辐合 700/850hPa 水汽通量散度 700hPa ≤ -10×10^-7 g/(cm²·hPa·s) 为强降水潜势参考；850hPa <0 表示低层水汽辐合 水汽在目标区域汇聚，配合上升运动时更容易出现短时强降水。 单位和符号需按资料源统一，负值代表辐合。
动力条件 500/700/850hPa 垂直速度 omega ω<0 为上升运动；≤-0.2Pa/s 可作为明显上升参考 反映天气系统抬升和中低层上升配合。 不同模式量级差异大，重点看上升区位置和趋势。
动力条件 700/850hPa 散度 低层散度 <0 表示辐合；若 200/300hPa 有资料，上层散度 >0 更有利 低层辐合和上层辐散配合时，抬升更有效。 需结合地面辐合线、海风锋、山地触发和雷达回波。
动力条件 0-6km 垂直风切变 12m/s 组织化参考；15m/s 较有利；20m/s 大风和强组织潜势更高 判断对流组织化、生命史和雷暴大风潜势。 强降水不一定要求很强切变，但大风和组织化对流更依赖切变。
动力条件 925/850hPa 或 0.5-3km 低空急流 ≥12m/s 为低层风速大值区参考；≥16m/s 入流和水汽输送更强 低层入流增强，支持对流维持、列车效应和短时强降水。 需用风廓线验证本地低层急流高度和到达时间。
对流指数 K 指数 32℃ 可能；35℃ 有利；38℃ 高潜势 综合反映低层水汽、垂直温度递减和中层干湿状况，适合强降水潜势参考。 K 指数高更偏向雷暴和强降水环境，不单独判大风。
对流指数 SI 沙氏指数 <0 不稳定；≤-3 明显不稳定；≤-6 强不稳定参考 SI 越负，层结越不稳定，对深对流越有利。 需确认系统使用的是沙氏指数还是抬升指数，符号口径不能混用。
综合判据 能量 + 水汽 + 抬升 + 切变 CAPE ≥1000、850q>8、MFD<0 或 ω<0、0-6km 切变 ≥12m/s 同时满足时，环境较有利 多指标一致时，未来 2-6h 对流发展或维持可信度提高。 短临结论必须同时给支持证据和限制条件，避免单阈值触发结论。

场景 关键量示例 中间判断 业务结论
短时强降水维持型 CAPE 1800J/kg，CIN 40J/kg，850q 10g/kg，PWAT 53mm，暖云层厚度 4.3km，925-700hPa 平均湿度 83%，0-1km 切变约 9m/s。 触发条件较好；降水效率高；天气分型为短时强降水型。 支持未来 2-6h 对流维持或增强，风险以短时强降水为主，可附带组织化雷暴风险。
有能量待触发型 CAPE 2300J/kg，但 CIN 180J/kg，850q 8g/kg，PWAT 32mm，LCL 1450m，LFC 2150m，500hPa 上升运动弱。 触发条件偏弱；降水效率低；天气分型为有能量待触发型。 不能仅因 CAPE 高就报强对流，需等待海风锋、低层辐合或上游回波进入后再上调预报。

3. 实况探空/TlogP模块

本模块只处理实况探空站资料，首期支持福州站、南平站，用 TlogP 图和实况指数校验当前环境层结。

模块定位

实况探空站属于观测资料，不属于数值预报模式。福州站、南平站提供温度、露点、风随高度变化和实况对流指数， 用于校验数值预报对层结、水汽、抑制和垂直风切变的判断。业务上与数值预报物理量相互印证，再进入雷达、卫星和风廓线跟踪。

资料类型：实况观测 探空站：福州/南平 图形：TlogP 作用：校验模式环境

数据边界

  • 福州站、南平站是实况探空站，输出观测 TlogP 和实况对流指数。
  • 探空资料按观测时次管理，不使用 EC/GFS 的起报时次和预报时效结构。
  • 探空结果可与数值预报物理量对比，但数据对象和配置保持独立。

地形/海拔修正要点

短临里要考虑，但主要影响低层和触发判读
结论：短临 TlogP 和物理量需要考虑地形、海拔和下垫面，但不建议把所有指标都简单做“海拔订正”。 CAPE、PWAT、K、SI 这类整层或气压层指标仍可作为环境背景；真正受地形影响最明显的是低层触发、局地环流、近地层温湿代表性，以及 0-1/0-3km 等按高度定义的诊断量。
关注点 为什么受地形影响 原型中建议怎么落
触发机制 海风锋、山谷风、坡面加热、迎风坡抬升和背风侧辐合会直接决定 2-6h 是否能起对流。 把地形作为触发修正层，输出沿海/平原/河谷/山区四类触发提示，不只给一个全市平均结论。
低层风和切变 0-1km 切变、低空急流、边界层辐合本质上依赖距地高度，山区和平原不能直接共用同一高度口径。 低层诊断统一按 AGL 解释，并用风廓线或自动站验证本地急流高度和到达时间。
TlogP 近地层解释 站点海拔和下垫面会改变近地层温湿结构、逆温强度和 LCL/LFC 的业务含义。 关键层位至少注明 AGL/AMSL；山区应用时更强调“距地多高开始自由对流”，而不是只看海拔高度。
资料代表性 福州/南平探空站更像区域背景场，不一定代表山谷、海岛或迎风坡局地环境。 综合诊断时写清“代表全区背景”还是“仅代表沿海/内陆背景”，局地结论继续依赖雷达、自动站和风廓线订正。
阈值本地化 同样 CAPE 或 CIN，在沿海平原和山地触发效率可能完全不同。 整层阈值可以先共用，触发类阈值和置信度建议按沿海、平原、河谷、山区分区维护。

对福州这类沿海且有山地背景的业务场景，更建议把地形做成“区域分区 + 触发修正 + 高度口径统一”的配置层，而不是为每个物理量单独维护一套复杂海拔订正公式。

TlogP 判读样例：与环境分型对应

不是只画线，还要服务触发和类型判断
判读口径：TlogP 不是独立给一个 CAPE/CIN 数值就结束，而应结合 LCL、LFC、湿层厚度、0℃层、湿球0℃层，直接说明它支持哪种环境分型； 山区或沿海应用时，关键层位应同时说明是距地高度还是海拔高度。
样例 图上应关注的层位或结构 对应解释
短时强降水型 近地层温露差小，湿层深厚；LCL 约 600m，LFC 约 1.0km；0℃层约 4.8km；湿球0℃层偏高。 表示低层容易抬升凝结，暖云过程明显，适合和 PWAT、暖云层厚度一起判断降水效率高。
触发受限型 近地层温露差较大，LCL 约 1.4km，LFC 约 2.1km；湿层偏浅，低层存在明显抑制。 即使 CAPE 偏高，也应提示“有能量但未必能触发”，防止在 2-6h 时效内提前报空。
雷暴大风或冰雹型 边界层偏干、中层直减率大；若湿球0℃层较低、-20℃层位置合适，则需额外关注冰雹。 同时结合 DCAPE、中层直减率、湿球0℃层与 TlogP 结构，体现强天气类型分流。

4. 风廓线模块

获取边界层到低层风场垂直结构，作为物理量/TlogP、雷达、卫星和实况资料之后的实时补充证据。

模块定位

风廓线用于判断当前本地所处天气系统位置和垂直结构，关注 0-1km、0-3km、0-6km 风切变、低空急流、风向随高度变化和垂直辐合信号。业务上在物理量/TlogP 定势、雷达/卫星定点后， 用于补充判断低层入流结构、系统移动进度、对流维持和大风潜势。福州地区首期支持福州站、罗源、闽清三个风廓线雷达站点切换。

实时 0-2h 实时补充 辅助判断低层结构 依赖质控

实施边界

  • 首期接入福州地区三个风廓线雷达站：福州站、罗源、闽清。
  • 低空急流、风切变阈值先采用研究初值，历史个例验证后本地化校准。
  • 输出作为实时风场证据进入综合诊断，不单独替代物理量/TlogP 定势和雷达识别。
