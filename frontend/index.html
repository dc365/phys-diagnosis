系统概览

从数值预报格点到天气形势诊断

后台把 ECTHIN、CMA-GFS 等模式资料映射到 NetCDF 格点场，转成天气系统、风险评分和可追溯证据链。

总体概述

把模式资料翻译成可复核的业务判断

系统围绕天气学最小分析闭环组织算法：先看大尺度形势背景，再检查水汽、抬升、不稳定和风切变，最后用阈值与权重矩阵给出诊断结论、评分和证据来源。

输入资料 ECTHIN / CMA-GFS
核心对象 高低压 / 槽脊 / 副高 / 急流 / 锋面
诊断方式 算法库 + 阈值矩阵 + 证据链
服务输出 API / 管理后台 / GIS 地图 / 任意点评分
处理流程

一次诊断从资料到结论的路径

5 步

数据接入

按模式、起报时间和预报时效读取 NetCDF，统一经纬度、层次、单位和缺测状态。

data_code / run_time / forecast_hour

物理量诊断

解析 500hPa、850hPa、700hPa、200/300hPa 等关键层次，计算散度、水汽通量、垂直速度和指数。

gh500 / div850 / w700 / kindex

天气系统识别

结合等值线、中心检测、线状对象和多边形区域识别高低压、槽线、脊线、副高、急流和锋面。

center / contour / line / polygon

风险评分

按六类风险评分算法输出持续性强降水、短时强降水、雷暴大风、冰雹、旋转风暴和强对流综合风险。

risk grid / score / source field

服务输出

输出天气对象、风险诊断、证据链、字段完整性和地图图层，支持接口调用与后台复核。

systems / risks / layers / point score

诊断思路

天气学证据链主线

形势背景

500hPa 位势高度、槽脊、副高和海平面气压决定系统配置。

gh500 / mslp / 5880gpm
水汽条件

850hPa 比湿、整层水汽和水汽输送带判断原料是否充足。

q850 / tcwv / moisture_flux850
抬升触发

低层辐合、高空辐散、700hPa 上升运动和锋区提供抬升条件。

div850 / div200 / w700 / front
不稳定

K 指数、CAPE、CIN 和温湿垂直结构决定对流能量释放难度。

kindex / cape / cin
风切变

垂直风切变和低空急流影响强对流组织化和降水维持。

shr850-200 / uv850 / low level jet
