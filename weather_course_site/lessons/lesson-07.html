气象知识 · 从物理量到业务分析

第 7 课：垂直运动

水汽要变成云雨，关键是空气能不能上升。

查物理量

本课目标

学会判断哪里有上升运动，以及上升运动为什么决定云雨发展。

1. 空气上升为什么会成云下雨

空气上升时气压降低，空气膨胀冷却；冷却到露点附近后，水汽凝结成云，云滴或冰晶继续增长就可能形成降水。

上升容易成云下雨，下沉容易晴朗少云。

2. 垂直速度 ω

业务模式图常用气压坐标的垂直速度 ω，单位常见 Pa/s。

ω 含义
ω < 0 气压变小，空气上升
ω > 0 气压变大，空气下沉

简单记：气压坐标里，负值通常是上升。

3. 为什么常看 700hPa 垂直速度

700hPa 位于中低层，常能反映大尺度上升运动，与云雨发展关系较密切。低层水汽充足且 700hPa 有上升，降水可信度更高。

4. 常见上升来源

来源 解释
低层辐合 空气在低层挤到一起，被迫上升
高空辐散 上方空气流走，下方空气被抽上来
冷锋 冷空气像铲子抬升暖湿空气
暖锋 暖空气沿冷空气上方滑升
地形 湿空气遇山被迫爬升
地面加热 近地面空气变暖变轻上升
高空槽前 高空动力扰动有利于上升
对流释放 不稳定空气被触发后快速上升 
有利上升：
高空辐散  ←   ↑   →
             ↑
低层辐合  →   ↑   ←


下面挤，上面抽，空气上升。

5. 大尺度上升和对流上升

大尺度上升像电梯，范围大、速度相对弱、持续时间长；对流上升像火箭，范围小、速度强、发展快。

本课一句话

有水汽没有上升，不一定下雨；有上升没有水汽，也不一定有明显降水。水汽是原料，上升是加工过程。
