气象知识 · 从物理量到业务分析

第 2 课：气压、高压、低压和等压线

看懂地面天气图的第一步。

查物理量

本课目标

看到地面天气图时，能快速判断高低压位置、风力大小和云雨倾向。

1. 气压是什么

气压可以理解为空气压在地面上的重量。气象业务中常用 hPa。高压和低压是相对概念：某地气压比周围高，就是相对高压；比周围低，就是相对低压。

2. 高压：多下沉，天气趋稳

高压中心附近，低层空气向外辐散，上方空气下沉补充。空气下沉会增温，相对湿度下降，云不容易发展。

高压 H：顺时针向外（北半球）


    ↘   ↓   ↙
  →     H     ←
    ↗   ↑   ↖


地面辐散 + 上方下沉 → 晴朗、少云、稳定

但高压不等于一定蓝天。冬季高压控制下，如果近地面逆温、风弱、湿度大，也可能有雾、霾、低云。

3. 低压：多上升，天气活跃

低压附近，低层空气向中心汇聚，空气被迫上升。上升冷却后，水汽容易凝结成云雨。

低压 L：逆时针向里（北半球）


    ↙   ↑   ↖
  →     L     ←
    ↘   ↓   ↗


地面辐合 + 上升运动 → 云多、降水概率高

低压也不等于一定暴雨，还要看水汽、上升强度和系统维持。

4. 等压线怎么看

等压线是气压相同的点连成的线。

现象 判断
越往中心气压越高 高压
越往中心气压越低 低压
等压线越密 气压梯度越大，风通常越大
等压线越稀 风通常较弱

5. 北半球风向口诀

低压逆时针向里，高压顺时针向外。

地面风受摩擦影响，会斜穿等压线，从高压一侧吹向低压一侧；高空风更接近平行于等高线或等压线。

6. 地面天气图 4 步法

  1. 找 H/L 或闭合等压线。
  2. 看等压线哪里最密，判断大风区。
  3. 看风从哪里来，判断冷暖空气和水汽来源。
  4. 看低压、锋面、切变线、辐合区附近是否有云雨潜势。

小练习

某地位于强高压和强低压之间，等压线非常密集，但空气干、无云系。可能天气是什么？

答案：大风风险较高，但不一定有降水。

本课一句话

地面图先找高低压，再看等压线疏密；低压附近容易上升成云雨，等压线密集处容易有大风。
