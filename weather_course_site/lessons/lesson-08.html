第 8 课：500hPa 位势高度、槽、脊和副高

500hPa 图看天气的大背景和高空指挥系统。

查物理量

本课目标

学会从 500hPa 图判断大尺度背景：槽、脊、副高、冷涡以及它们对降水、冷空气和强对流的影响。

1. 位势高度

位势高度可以简单理解为某个气压面离地面的高度。暖空气柱膨胀，500hPa 面较高；冷空气柱收缩，500hPa 面较低。

500hPa 图上的等高线常写作 568、576、588 等，588 通常约等于 5880 gpm。

2. 槽

槽是等高线向低纬度，也就是向南凹出的区域。

槽：等高线向南凹


  \      /
   \    /
    \  /
     \/
    槽线


槽前常有利于上升和天气发展。

在中纬度西风带中，槽的东侧通常叫槽前，西侧叫槽后。槽前常有利于上升运动、云雨发展；槽后常有冷空气、下沉或天气转好，但冷涡槽后也可有阵性天气。

3. 脊

脊是等高线向高纬度，也就是向北凸出的区域。

脊：等高线向北凸


     /\
    /  \
   /    \
  脊区


脊区多下沉，天气通常较稳定。

4. 副热带高压

副高是夏季我国天气的关键系统。副高内部常有下沉运动，晴热少雨；副高边缘常有偏南暖湿输送，容易出现强降水。

副高内部晴热，副高边缘容易出暴雨。

588 线常用于分析 500hPa 副高范围，但不是绝对降水边界。

5. 冷涡

冷涡是高空闭合低值系统，中心较冷，气流气旋式旋转。常造成阵雨、雷阵雨、冰雹、雷暴大风等阵性和对流性天气。

6. 500hPa 与其他层配合

层次 主要看什么
500hPa 槽脊、副高、冷涡、大背景
850hPa 水汽输送、低空急流、低层冷暖
700hPa 上升运动、中层湿度
地面 锋面、低压、切变线、触发

本课一句话

500hPa 图不是直接看雨，而是看大背景；找槽、脊、副高和冷涡，再结合低层水汽、700hPa 上升和地面触发判断天气。
