# 气象物理量课程 Web 网站

这是一个可离线打开的静态课程网站，面向气象行业从事者，内容覆盖天气学基础、物理量、探空、雷达、数值模式释用和个例复盘。

## 使用方法

方式一：直接双击 `index.html` 打开。

方式二：本地启动静态服务：

```bash
cd weather_course_site
python3 -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

## 目录结构

```text
weather_course_site/
├── index.html                 # 课程首页
├── glossary.html              # 物理量速查表
├── cases.html                 # 个例复盘模板
├── learning-path.html         # 学习路线

├── assets/css/styles.css      # 样式
└── assets/js/                 # 搜索、目录、学习进度脚本
```

## 特性

- 无需构建、无需后端、可离线使用。
- 支持课程搜索、物理量搜索。
- 支持本地浏览器学习进度记录（localStorage）。
- 支持移动端浏览和打印。
